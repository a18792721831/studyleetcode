# studyleetCode

LeetCode 刷题记录，Go 实现。按题号分目录，每题一个可直接运行的 `main.go`（含测试用例与踩坑注释）。

## 环境

- go 1.21+（部分题使用内建 `min` / `max`）
- 多版本管理使用 [g](https://github.com/voidint/g)：`g use <version>` 切换，用完切回

```bash
go run ./718
```
